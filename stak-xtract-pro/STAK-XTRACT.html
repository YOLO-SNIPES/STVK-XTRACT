OVERVIEW

STAK-XTRACT is an AI-powered audio sample extraction and arrangement tool designed for music producers, beatmakers, and audio enthusiasts. It uses advanced machine learning algorithms to intelligently identify and extract samples from audio files.

GETTING STARTED

  1. Start the engine (for real analysis): Run launch.sh — it starts engine/server.py on port 8777. The ENGINE pill in the header turns green when it is online. Without it, the app still shows waveforms but will not invent analysis.
  2. Upload Audio: Click [UPLOAD_AUDIO.exe] to select an audio file from your device (supports MP3, WAV, OGG, FLAC, M4A)
  3. Load Sample: Or click [LOAD_SAMPLE_PACK.exe] to use the provided demo audio
  4. Configure Analysis: Choose your analysis type and sensitivity level
  5. Execute Scan: Click [EXECUTE_AI_SCAN.exe] to analyze the audio
  6. Review Samples: View extracted samples in the waveform and sample grid
  7. Arrange: Drag samples to create arrangements or use AI generation
  8. Export: Download your samples as real .wav files in a ZIP file
  9. Create MIDI: Use CREATE_MIDI to generate a MIDI starter (chords, bass, drums, melody + arrangement sketch) from one of your analyzed tracks

ANALYSIS TYPES

Sample Extraction

Identifies distinct musical elements like drums, bass, leads, and vocals

Beat Detection

Focuses on rhythmic elements and percussive sounds

Melody Analysis

Extracts melodic and harmonic components

Full Analysis

Comprehensive analysis combining all detection methods

SENSITIVITY LEVELS

Low: 3-8 samples - Extracts only the most prominent elements
Medium: 8-15 samples - Balanced detection (recommended)
High: 15-25 samples - Detects subtle elements and variations

WAVEFORM CONTROLS

[+]: Zoom in for detailed view
[-]: Zoom out for overview
[RST]: Reset to default zoom level
Colored Segments: Visual representation of extracted samples

ARRANGEMENT FEATURES

Drag & Drop: Drag samples from the grid to the arrangement track
Click to Add: Use the "Add" button on each sample card
[CLR]: Clear all samples from arrangement
[PLAY]: Play the current arrangement sequence
[AI_GEN]: Generate optimal arrangement using AI
← →: Scroll arrangement track horizontally
Reorder: Use ◀ ▶ buttons to move samples within arrangement

EXPORT OPTIONS

Formats: MP3, AIF, M4A
Quality: High/Medium/Low compression
Sample Rate: 44.1kHz, 48kHz, 96kHz
Output: ZIP file containing sample metadata and arrangement data

TIPS & TRICKS

  • Use higher sensitivity for complex tracks with many layers
  • Try different analysis types to focus on specific elements
  • Clean, high-quality source audio produces better results
  • AI arrangement considers energy levels and musical flow
  • Experiment with different zoom levels for precise sample boundaries
  • Each sample shows duration, energy level, and detected pitch

// FAQ.exe //

Q: What audio formats are supported?

A: STAK-XTRACT supports MP3, WAV, OGG, FLAC, M4A, and most common audio formats. For best results, use uncompressed formats like WAV or FLAC.

Q: How accurate is the AI sample detection?

A: The AI achieves 85-95% accuracy depending on audio quality and complexity. Clean, well-mixed tracks produce the best results. Complex polyphonic music may require manual adjustment.

Q: What's the maximum file size I can upload?

A: File size limits depend on your browser and device memory. Generally, files up to 100MB work well. Longer tracks may take more time to process.

Q: Can I edit the detected sample boundaries?

A: Currently, sample boundaries are automatically detected by the AI. Future versions will include manual editing capabilities. You can influence detection using different sensitivity settings.

Q: Does STAK-XTRACT work offline?

A: Analysis runs on your own machine through the local engine bridge (engine/server.py, port 8777), which uses the YOLO music utility — librosa feature extraction, honest numbers, no invented samples. Audio never leaves your device. Waveform visualization works offline once audio is loaded.

Q: Why do I only get JSON files in the export?

A: The official version exports real audio: each sample is sliced from your file and written as a .wav, plus samples.json metadata and arrangement.json. The old preview exported JSON only.

Q: What makes the AI arrangement feature special?

A: The AI considers musical factors like energy levels, rhythm patterns, and harmonic relationships to create coherent arrangements that flow naturally.

Q: Can I use STAK-XTRACT for commercial projects?

A: You can use STAK-XTRACT for analysis, but ensure you have proper rights to the source audio. Always respect copyright laws and licensing agreements.

Q: The analysis is taking too long. What should I do?

A: Long tracks or high sensitivity settings may take 30-60 seconds. Try reducing sensitivity or using shorter audio segments. Check your internet connection.

Q: How do I get the best results?

A: Use high-quality source audio, start with medium sensitivity, choose the appropriate analysis type, and ensure the audio isn't heavily distorted or compressed.

Q: Is my audio data stored or transmitted?

A: Audio analysis data is processed by AI services but not permanently stored. See our Privacy Policy for complete details on data handling.

Q: Can I contribute to the project?

A: STAK-XTRACT is developed by YOLO SNIPES. For feedback, suggestions, or collaboration opportunities, contact the developer through the Poe platform.
